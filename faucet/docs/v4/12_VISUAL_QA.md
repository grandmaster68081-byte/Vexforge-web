# VISUAL QA SCRIPT

Capture screenshots at:
- 1440×900
- 1280×800
- 390×844
- 412×915

Review:
1. Is the environment immediately visible?
2. Is the primary object visible without scrolling?
3. Does the screen have one dominant action?
4. Are there large flat card clusters? If yes, fail.
5. Is the scene recognizably different from the previous screen?
6. Are supplied art assets visible and well integrated?
7. Does mobile retain the same identity without a sidebar?
8. Does reduced motion remain legible?
