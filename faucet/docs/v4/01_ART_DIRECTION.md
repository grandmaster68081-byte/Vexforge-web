# KIVORA V4 — ART DIRECTION

## Identity
Kivora is a **neon orbital rewards station** at the edge of a living sky-city. The user is an operator inside that station. The product language is not cyberpunk clutter; it is clean, premium science-fiction with strong silhouettes and controlled luminous accents.

## Visual hierarchy
1. World/environment
2. Hero object / station instrument
3. User goal
4. Data
5. Secondary controls

## Materials
- carbon black
- dark blue metal
- smoked glass used sparingly
- cyan energy
- ultraviolet signal
- lime completion state
- gold settlement state

## Prohibited look
- generic Web3 dashboard
- wall of cards
- purple gradient as primary identity
- decorative 3D blob with no semantic purpose
- AI-stock neon city wallpaper used as a background without composition

## Signature objects
- Kivora Core
- Opportunity Gates
- Vault Chamber
- Chronicle Rail
- Settlement Beacon

## Type system
Display: geometric/architectural sans.
UI: neutral readable sans.
Technical: monospace for transaction IDs, hashes and provider metadata.
