# KIVORA V4 — SCENE SYSTEM

## Command Deck
Hero: Kivora Core inside a station chamber.
Purpose: orient the user and start the Daily Run.
Key interaction: Enter Run.

## Opportunity Field
Hero: distributed opportunity gates in a field.
Purpose: browse and choose real provider opportunities.
Each category owns a visual motif instead of identical cards.

## Vault
Hero: physical/digital storage chamber.
Purpose: explain available, pending and reserved balances.

## Chronicle
Hero: vertical event rail.
Purpose: show verified earning evidence and state transitions.

## Settlement Terminal
Hero: a staged terminal with reserve → review → broadcast → paid.
Purpose: make manual payout understandable and trustworthy.
