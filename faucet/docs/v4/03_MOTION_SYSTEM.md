# KIVORA V4 — MOTION SYSTEM

## Idle
Core breathes slowly. Peripheral signals move at low amplitude.

## Navigate
Scene transition: 320–520ms, spatial crossfade + depth shift. No generic page fade.

## Opportunity open
Gate brightens, metadata resolves, reward signal becomes legible.

## Reward verified
Signal travels from provider marker → Core → Vault. Use one continuous motion path.

## Reserve withdrawal
Available balance contracts; reserved balance illuminates in violet.

## Paid
Settlement beacon switches gold; TX hash appears as immutable evidence.

## Reduced motion
Disable parallax and orbital motion. Preserve hierarchy and state through static visual markers.
