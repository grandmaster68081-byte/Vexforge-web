# ANTI-GENERIC-DASHBOARD RULES

Reject any implementation that merely:

- renames menu items;
- keeps the existing card grid and swaps headings;
- adds a gradient background;
- adds more glow or border effects;
- uses a single generic background on every screen;
- uses stock-looking neon artwork without semantic placement;
- treats the Core as a circle made only with CSS;
- makes the mobile version a long vertical list of desktop cards.

The V4 result must feel like a place, not a component catalogue.
