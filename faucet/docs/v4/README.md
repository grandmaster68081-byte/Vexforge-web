# KIVORA V4 — TRUE PREMIUM DIEGETIC PRODUCT IMPLEMENTATION

This package replaces the previous V3 direction. It is intentionally concrete: visual identity, scene composition, artwork, interaction language, motion choreography, responsive behavior, and React implementation scaffolding are included.

## Product premise

Kivora is not a generic faucet dashboard. It is a **Daily Earning Station**: a diegetic environment where earning opportunities are represented as places, signals and instruments; rewards become visible state changes; the wallet is a vault; history is a chronicle; withdrawals are settlements.

## Core visual thesis

**Earn • Explore • Grow**

The user should want to stay in the environment even before completing an offer. The UI is designed as a game-like workstation, not as a card catalogue.

## What is included

- Two generated Kivora art-direction boards.
- Cropped production-oriented environment assets.
- A fully navigable single-file visual prototype.
- React/TypeScript components and scene shells for direct integration.
- Motion/state choreography.
- Responsive rules for mobile instead of desktop shrinkage.
- Exact implementation order and acceptance criteria for Replit.
- A strict no-interpretation handoff: Replit executes, it does not redesign.

## Provider state

The visual prototype does not require BitcoTasks credentials. It renders the provider as **Ready / Not Configured** as a normal state. Real provider integration remains a separate runtime layer.

## Treasury state

USDT / TRC20 is the product payout rail defined by the current project contract. The public treasury address is displayed only as public destination metadata. No private key, seed phrase, or wallet secret is included.

## Implementation rule

Use this package as the visual/product source of truth. Preserve the existing Supabase, ledger, postback, withdrawal and Cloudflare architecture; replace the authenticated presentation layer with the V4 scene system.
