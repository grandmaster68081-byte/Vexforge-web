# KIVORA V4 — MOBILE ART DIRECTION

Mobile is a scene, not a squashed desktop.

## Order
1. Hero object
2. Core metric
3. Primary action
4. One secondary signal
5. Swipe/scroll into the rest of the scene

## Navigation
Bottom dock may be used only if necessary; preferred behavior is a compact persistent station rail with the active scene represented by a luminous glyph.

## Avoid
- 5 stacked cards above the fold
- tiny desktop tables
- large left sidebar consuming the viewport
