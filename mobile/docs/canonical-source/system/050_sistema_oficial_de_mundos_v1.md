  # Sistema Oficial de Mundos v1

Los mundos organizan la progresión geográfica y narrativa del juego.

## Función
- Ordenar el avance
- Subir dificultad
- Desbloquear enemigos y bosses
- Introducir nuevas facciones y mecánicas

## Reglas
- Cada mundo tiene identidad propia.
- Cada mundo tiene curva de dificultad.
- Cada mundo puede asociarse a recompensas y pools específicos.

## Regla oficial
Los mundos no son decoración: son progreso real y contenido jugable.
