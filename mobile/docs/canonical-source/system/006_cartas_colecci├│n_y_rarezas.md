  # Cartas, Colección y Rarezas

Las cartas son el núcleo de identidad del jugador.

Cada carta tiene:
- rareza
- facción
- imagen oficial
- valor de colección
- función dentro del combate
- función dentro del mercado
- función dentro de la fusión
- función dentro de la progresión

La colección debe sentirse viva y estratégica.
