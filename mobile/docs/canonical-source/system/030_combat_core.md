  # Sistema Oficial de Combate v1

El combate es el motor jugable principal de VEXFORGE.

## Modos
- PvE
- PvP
- Bosses
- Raids
- Eventos especiales

## Qué debe resolver el combate
- Uso de cartas
- Consumo de energía
- Aplicación de daño
- Activación de habilidades
- Recompensas
- Progreso de misiones

## Regla oficial
El combate debe ser rápido, claro, táctico y viable en Mini App.

## Objetivo de diseño
Que el jugador entienda el combate en segundos y lo domine con estrategia a largo plazo.
