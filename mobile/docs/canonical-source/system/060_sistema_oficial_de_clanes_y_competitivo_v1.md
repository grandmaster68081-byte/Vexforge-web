  # Sistema Oficial de Clanes y Competitivo v1

La capa social convierte VEXFORGE en una experiencia colectiva.

## Incluye
- Clanes
- Roles internos
- Guerra de clanes
- Territorios
- Ranking de temporada
- Contribución grupal

## Objetivo
- Crear pertenencia
- Crear cooperación
- Crear competencia real
- Crear identidad comunitaria

## Regla oficial
Un jugador solo progresa; un clan construye poder colectivo.
