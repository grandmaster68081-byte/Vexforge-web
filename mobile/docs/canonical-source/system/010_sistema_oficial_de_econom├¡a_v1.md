  # Sistema Oficial de Economía v1

La economía de VEXFORGE está diseñada para ser estable, controlada y trazable.

## Principios clave
- Toda generación de valor debe venir de acciones del jugador.
- Toda salida de valor debe tener reglas claras.
- Toda recompensa debe registrar trazabilidad.
- El sistema debe evitar inflación y abuso.

## Recursos principales
- VEX in-game
- VEX tradeable
- Gold
- Energía

## Fuentes
- Misiones
- Combate
- Eventos
- Packs
- Recompensas de progreso

## Sinks
- Energía
- Mercado
- Fusiones
- Mejoras
- Retiros

## Regla oficial
La economía nunca debe permitir creación infinita de valor sin coste, límite o fricción.
