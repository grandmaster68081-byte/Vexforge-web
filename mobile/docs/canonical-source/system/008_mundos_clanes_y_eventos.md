  # Mundos, Clanes y Eventos

El universo se organiza por:
- mundos
- facciones
- clanes
- guerras
- eventos globales

Estas capas dan ritmo, identidad, competencia y vida al proyecto.

El mundo oficial debe poder crecer sin romper el balance.
