  # Combate, PvE, PvP y Bosses

El combate es el corazón jugable de VEXFORGE.

Debe conectar:
- decks
- energía
- cartas
- habilidades
- enemigos
- bosses
- raids
- recompensas
- progreso

El combate oficial debe ser claro, táctico y viable con herramientas ligeras.
