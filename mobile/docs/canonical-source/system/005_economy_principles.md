  # Principios Oficiales de Economía

La economía de VEXFORGE se sostiene sobre:
- fuentes controladas
- sinks claros
- límites reales
- trazabilidad

La moneda interna, el mercado, las recompensas, las fusiones, el consumo de energía y los retiros deben permanecer equilibrados para evitar inflación o abuso.
