  # Sistema Oficial de Progresión del Jugador v1

La progresión debe ser visible, acumulativa y significativa.

## Ejes de progreso
- Nivel de cuenta
- Poder de colección
- Progreso de mundos
- Prestigio
- Logros y maestría

## Lo que desbloquea
- Misiones nuevas
- Cartas nuevas
- Mundos nuevos
- Modos avanzados
- Recompensas mayores

## Regla oficial
El jugador nunca debe avanzar sin sentir que realmente ganó algo.
