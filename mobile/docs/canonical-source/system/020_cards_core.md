  # Sistema Oficial de Cartas v1

Las cartas son la unidad central del juego.

## Qué representa una carta
- Una unidad de poder
- Una identidad visual
- Un elemento de colección
- Un recurso económico
- Un componente de combate

## Propiedades base
- Nombre
- Rareza
- Facción
- Tipo
- Imagen oficial
- Estadísticas
- Nivel
- Estado de evolución

## Reglas clave
- Toda carta debe estar vinculada a un asset oficial.
- Toda carta debe poder usarse en combate o progresión.
- Los duplicados deben tener valor funcional.
- La colección debe sentirse viva y estratégica.
