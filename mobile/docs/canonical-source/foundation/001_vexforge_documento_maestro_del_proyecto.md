  # VEXFORGE · Documento Maestro del Proyecto

VEXFORGE es un universo oficial de cartas, combate, progresión, economía y mundo vivo.

Toda la lógica oficial del proyecto debe leerse desde Supabase como fuente única de verdad para la implementación en Replit y la Mini App.

Este documento actúa como punto de entrada del ecosistema oficial.
