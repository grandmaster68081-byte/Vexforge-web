  # Política Oficial de Assets Visuales

Los assets visuales oficiales del proyecto viven en Supabase Storage y se organizan mediante manifiestos.

Cada pack representa una familia visual:
- cartas
- logos
- marcos
- fondos
- UI
- wallet
- mercado
- clanes
- mundos
- tutorial
- eventos
- recompensas

Replit debe leer el manifiesto, no inventar assets.
