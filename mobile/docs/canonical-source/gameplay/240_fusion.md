  # Sistema Oficial de Fusión

Permite consumir duplicados.

Resultado:

Aumento de nivel.
Mejora estadística.
Desbloqueo de evolución.

Beneficios:

Reduce inflación de cartas.
Da valor a duplicados.
Aumenta progresión.

Regla oficial:

Ninguna carta sobrante debe sentirse inútil.
