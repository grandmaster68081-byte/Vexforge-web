  # Sistema Oficial de Temporadas

Duración:

30 días.

Cada temporada incluye:

Misiones nuevas.
Ranking nuevo.
Recompensas nuevas.
Eventos nuevos.

Objetivo:

Mantener el juego vivo.

Regla oficial:

Cada temporada debe sentirse diferente.
