  # Alcance Oficial del MVP

## Lo que sí entra al MVP
- Bot de Telegram
- Mini App básica
- Inicio
- Misiones
- Cartas
- Perfil
- Inventario
- Mercado básico
- Fusión básica
- Progreso
- Ranking
- Eventos simples
- Clanes básicos
- Economía controlada
- Integración de assets oficiales

## Lo que puede quedar para después
- Bosses complejos
- Raids avanzadas
- Guerra de clanes profunda
- Eventos narrativos masivos
- Animaciones elaboradas
- Sistemas de IA del mundo más sofisticados

## Regla oficial
El MVP debe ser jugable, estable y coherente, aunque no tenga todavía toda la profundidad final.
