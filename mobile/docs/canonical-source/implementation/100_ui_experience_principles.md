  # Principios Oficiales de UI y Experiencia

La interfaz de VEXFORGE debe ser clara, ligera, móvil y coherente con Telegram Mini App.

## Reglas base
- No saturar al jugador con texto técnico.
- No mostrar nombres internos de tablas, RPC o IDs.
- Priorizar lectura rápida en móvil.
- Mantener estética consistente entre Bot, Mini App y assets oficiales.
- Cada pantalla debe tener una función clara.

## Objetivo visual
La UI debe parecer un juego vivo, no un panel administrativo.

## Regla crítica
Si una pantalla no ayuda al jugador a jugar, progresar o entender su estado, no debe mostrarse como parte principal del flujo.
