  # Reglas Oficiales para Replit

Replit debe construir el juego leyendo siempre Supabase como fuente única de verdad.

## Reglas de implementación
- No inventar pantallas no documentadas.
- No inventar assets no registrados.
- No alterar rarezas ni roles de imágenes.
- No mostrar datos técnicos al jugador.
- No romper la estructura oficial del diseño.

## Regla de lectura
Replit debe leer:
- documentos oficiales
- mapas de módulos
- manifiesto de assets
- datos de jugador
- estado de economía
- progreso de combate

## Regla de seguridad
Si algo no está documentado o registrado en Supabase, no debe asumirse como oficial.
