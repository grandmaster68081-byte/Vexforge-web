# VEXFORGE public-copy policy

Public copy is written for players, collectors and people discovering the game for the first time. It must describe the product, not the machinery used to produce it.

Allowed topics: game, cards, collection, battle, strategy, world, factions, news, media, support, availability, platforms, official download state.

Forbidden topics: internal architecture, backend vendors, database details, APIs, engineering frameworks, build/deployment status, source/repository details, environment variables, asset identifiers, debugging, staging, unfinished implementation notes.

The pre-release status may be communicated only where it is useful to the player, such as the dedicated download surface.
