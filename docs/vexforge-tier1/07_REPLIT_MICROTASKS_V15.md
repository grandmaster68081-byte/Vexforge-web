# REPLIT MICROTASK CONTRACT · V15

The package is already designed. Replit's job is to apply, compile-check, run the supplied validations and commit. It should not redesign.

## Commit discipline

One microtask → one verification → one commit → one continuity update.

- `V15-01 canonical Tier-1 overlay apply`
- `V15-02 account-scoped continuity`

- `V15-15 production continuity seal`

## Stop conditions

Stop and write the failure into continuity if:

- the canonical battle signature differs;
- Unity version differs;
- the repo is not the intended remote or branch;
- a duplicate GUID appears;
- a new backend endpoint appears without an authoritative contract;
- an official card is copied into the client;
- the Unity Editor reports a compile error;
- live Supabase returns a schema mismatch.

Do not solve a stop condition by inventing a workaround.
