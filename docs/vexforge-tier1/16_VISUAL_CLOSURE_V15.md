# VISUAL CLOSURE · V15

## Identity rule

VEXFORGE should look like a place that exists before the player taps it. Controls are framed as seals, plaques, portals and relics. Screens are rooms. Battle is an arena. Rewards are artifacts. Cards are objects inside that world.

## What quality means here

Quality is not maximum number of effects. It is controlled hierarchy, coherent materials, readable depth, responsive transitions and a visual response that explains what just happened.

## Card presentation

The official artwork stays intact. The surrounding presentation supplies:

- perspective/depth;
- rarity-appropriate frame treatment using the supplied frame assets;
- subtle highlight and shadow separation;
- event-scoped emphasis;
- readable enlarged view where supported by the existing gallery/detail path.

## Battle presentation

Battle receives the highest audiovisual budget because it is the core loop: board scale, opponent/boss focus, event-driven impact, short reveal motions, zone readability, contained energy and a result moment after the event stream finishes.

## Missing authored content

When a bespoke boss model, pack sequence, prop or environment asset is not available in Storage, the runtime uses a stylized VEXFORGE procedural stand-in with the same palette and silhouette language. It is a fallback, not a claim that the missing final 3D asset has been created.
