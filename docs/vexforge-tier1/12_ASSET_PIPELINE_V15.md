# ASSET PIPELINE · V15

## Three asset classes

### Class A · Official content

The 127 card artworks. Source: Supabase Storage. Never copied or regenerated by V15.

### Class B · Identity support art

Arena, Nexus, Forge, Archive, Mission Hall, Treasury, pack vault, card frames, sigils and card back. V15 bundles the local support assets that exist in the current payload.

### Class C · Runtime procedural dressing

Meshes, rings, zones, seals, lighting and encounter manifestations created by code when authored 3D content is not yet present.

## Upgrade path

Class C is intentionally deterministic so later authored 3D assets can replace the procedural piece without changing battle logic or navigation. The contract should remain asset-ID based.

## Visual quality rule

A missing asset must fail into a deliberate composition, not into a developer placeholder, white screen or primitive boss capsule.
