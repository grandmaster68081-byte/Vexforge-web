# VEXFORGE V5.2 — Premium / Tier-1 Visual Upgrade

## Why V5.1 was not the final visual target
The supplied mobile recording shows that the V5.1 architecture is structurally clean but still visually under-filled. The dominant failure is not lack of content; it is **material hierarchy**. Several sections read as text placed on black rather than as parts of one living game world.

### Observed issues
1. Large near-black gaps between visual chapters.
2. Artwork is frequently darkened so heavily that the image becomes secondary.
3. Interior pages use the same dark field too often, creating visual fatigue.
4. Cards can fall into a near-empty/black state when an official image is missing.
5. Faction panels need stronger visual identity and material framing.
6. Section transitions do not feel like one continuous premium game property.
7. Mobile composition becomes text-heavy after the first hero instead of maintaining image-led rhythm.
8. Some surfaces resemble refined editorial web UI rather than a premium game portal.

## V5.2 changes
- Introduced a warmer obsidian/stone material field while retaining dark medieval identity.
- Increased legitimate artwork exposure; overlays protect readability without burying the source art.
- Added subtle forged-metal/engraved borders and chapter rails using CSS only.
- Added atmospheric section transitions so the page no longer collapses into dead black.
- Added a VEXFORGE seal treatment to the Home introduction using the existing ForgeGlyph.
- Strengthened card presentation and created an official-art fallback using the existing VEXFORGE cover when a public card has no approved image.
- Added faction-specific accent treatment using the existing faction tone metadata.
- Increased depth through restrained shadows, edge lighting, inner frames and warm hierarchy.
- Preserved the no-SaaS rule: no dashboards, fake metrics, HUD panels, particle fields or glass-heavy UI.
- Preserved real-data boundaries and empty download URLs.

## Visual acceptance target
A visitor should perceive this sequence as one product: **cinematic world → game identity → collection → factions → world → official release gate**, not a sequence of unrelated black website sections.

## Non-negotiable constraints
- Use only official VEXFORGE assets already referenced by the package.
- Do not invent card names, stats, screenshots, release dates or social links.
- Do not alter Supabase schema/RPC/auth.
- Do not touch Unity.
- Do not add authentication to the public portal.
