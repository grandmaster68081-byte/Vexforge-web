# VEXFORGE — TIER-1 SCORECARD

Use this to decide what to improve next. It is a directional engineering/product scorecard, not a claim that VEXFORGE already meets the market's top benchmark.

Score each category 0–5 based on evidence.

## Functionality

0 = broken
1 = unreliable
2 = partially working
3 = stable core flow
4 = robust with good edge-state handling
5 = production-grade behavior verified across expected paths

## Navigation

0 = trapped/broken
1 = inconsistent
2 = usable but fragmented
3 = coherent
4 = contextual and predictable
5 = feels native to the game world

## Visual identity

0 = generic/admin
1 = cosmetic theme only
2 = inconsistent game skin
3 = recognizable VEXFORGE
4 = strong premium identity
5 = clearly competitive with leading TCG presentation principles while remaining original

## Motion/game feel

0 = static
1 = isolated effects
2 = basic transitions
3 = responsive interaction system
4 = coherent motion language
5 = premium, purposeful, performant game feel

## Collection

0 = broken list
1 = functional database
2 = usable catalog
3 = strong collection
4 = collectible experience
5 = high-desire, high-discovery TCG collection experience

## Deckbuilding

0 = broken
1 = editor only
2 = functional deck builder
3 = strategic workspace
4 = integrated with collection/battle
5 = signature VEXFORGE "Forja" experience

## Battle entry / arena

0 = broken
1 = technical launcher
2 = usable mode picker
3 = strong arena entry
4 = immersive competition hub
5 = convincing premium TCG gateway into the match loop

## Profile / identity

0 = settings page
1 = stats page
2 = profile
3 = identity hub
4 = player legacy
5 = aspirational social/status space

## Reliability

0 = frequent failure
1 = fragile
2 = moderate defects
3 = stable
4 = strong recovery/observability
5 = mature regression discipline

## Target

Do not chase a cosmetic 5/5 while functionality remains 0–2 in a core category.

Preferred order:

`FUNCTION ≥ 3 → INTEGRATION ≥ 3 → VISUAL ≥ 3 → MOTION ≥ 3 → PROGRESSIVE TIER-1 POLISH`
