# docs/

Esta carpeta contiene documentación técnica específica del frontend.

La documentación operativa activa vive en la raíz del repositorio:

1. `VEXFORGE_PROTOCOL_V2.md` — protocolo vigente.
2. `CONTINUITY.md` — estado actual, evidencia, bloqueos y siguiente acción.
3. `backend/` — arquitectura, decisiones y handoff técnico.

Los documentos históricos retirados no son fuentes de instrucciones actuales. El historial de Git se conserva para auditoría y reversión.
